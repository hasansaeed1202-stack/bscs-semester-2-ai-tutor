# CS-125T — Object Oriented Programming (Th)

**University:** Sarhad University of Science & Information Technology, Peshawar  
**Department:** Computer Science and IT  
**Credit Hours:** 3-0  
**Course Duration:** One Semester  
**Credit Units:** 3  
**Level:** 2nd Semester, 1st Year  
**Prerequisites:** Programming Fundamentals

## Course Objectives

In this course the students will be able to:

- Remember principles of object-oriented paradigm.
- Understand mapping of real-world objects into a programming model.
- Model and analyze relationships between classes and objects.
- Apply OOP techniques to solve the complex real-world problems.

## Course Learning Outcomes

### CLO-01
Describe the fundamental concepts of object-oriented programming, including classes, objects, data encapsulation, member access specifiers, and member functions.

### CLO-02
Apply advanced object-oriented programming techniques using encapsulation, abstraction, inheritance and polymorphism.

### CLO-03
Analyze object-oriented solutions using class relationships (association, aggregation), file handling, pointers, and templates in the context of the Standard Template Library (STL).
